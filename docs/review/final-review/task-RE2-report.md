## NEEDS A RULING

**FR-194: a library close during the "found" panel, the "cannot tell" state or the form.** This still holds. `Library.tsx` `holdClose` is set only through `onRecoveryPending`, that is, by the recovery-code step, and that step stays held. Any other close unmounts the dialog and leaves the library screen, which loses the notice. There are two behaviours to decide between:
- (a) **The "found" panel of an encrypted project.** It carries the only telling that the recovery code was never shown and that the passphrase is the only way in. Hold the close there exactly as the recovery-code step is held: set `holdClose` while `found?.encrypted`, add the closed-library line, and let "Open the project" leave. Recommended. The wording would reuse the existing sentence: "The library was closed while this was open. The project was created; once you have read this, you return to choosing a library." with the button "Back to choosing a library".
- (b) **"Cannot tell", in the dialog and in the notice.** Holding is pointless here: once the library is closed, "Check again" cannot read its list. What is needed is a decision on whether the chooser should carry a notice (on this computer, without the passphrase) such as: "When “X” was being created in “Library”, the app could not tell whether it was made. When you open that library again, look for “X” in its list of projects before creating it again." Recommended: show it in the chooser for the session only, keep nothing on disk, and give it "Got it". That makes it larger than M, so I did not start it.
- (c) **The plain form.** Nothing is lost there, so the current behaviour is fine.

**FR-204/205, a remaining point.** The dialog and the notice now say how many projects appeared and choose none. They do not tell the same-named projects apart, because the only difference the screen holds is each project's folder inside the library (for example "Projects/Clinic follow-up 2"), and showing it would put a folder name on screen. Decide whether to list them by folder ("in the folder “Clinic follow-up 2”") or leave them as they are now, pointed to in the list of projects. I recommend listing them by folder name only (the last part), through `UserText`, each with its own "Open this one" button.
