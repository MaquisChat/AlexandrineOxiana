## What the task is
When a library is moved, the old copy stays where it was until the researcher deletes it. If files are later DESTROYED in the library (a participant's withdrawal, a retention date), an old copy still holds them. The task makes the destruction's certificate say so and raises a warning (`destruction-old-copies-pending`) that lasts until the old copy holds none of the destroyed data. Two principles decide every case: **the warning errs toward staying** (it ends only when the old place was looked at and holds none of the data; anything else is "cannot tell"), and **a certificate says only what is known** (it is evidence, written once).
