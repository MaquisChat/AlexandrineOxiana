## Why
The project's owner (a researcher, not a programmer) created a library on a disk with little room and imported a Zotero library of thousands of items into it; the disk filled and the import stopped. The app has no default place for a library: on first run the "Library folder" box of the screen "Choose a library" is empty, and nothing says how much room the chosen disk has. The owner asked for two things: a SUGGESTED folder, and the FREE ROOM on the disk under the chosen folder.

## The ruling — read it in full, every clause binds

In short: (a) the chooser shows ONE suggested folder under the "Library folder" box — "Suggested: <folder>" and a button "Use this folder" (accessible name "Use the suggested folder") that fills the box; the box is never prefilled and nothing is created by the button. The service works it out: `<home>/Documents/Alexandrine Oxiana` when Documents exists and is not a cloud-synced place by the app's own classification; else `<home>/Alexandrine Oxiana`; if that folder exists and is not empty, the same name with " 2" … " 9" (the first that does not exist or is empty); if none, no suggestion. (b) Once the box holds a full path, the chooser shows "Free space on that disk: 212 GB." (for a folder that does not exist yet: the nearest existing folder above it); under 10 GB it adds "That is little room: an import copies its files into the library."; when the room cannot be told (two seconds without an answer, an unreadable place) NOTHING is shown; an answer for a path the box no longer holds is dropped. (c) Two service routes for the app's screens only: the suggestion (no input) and the room for a path (the path in the request BODY, never in an address; a full local path only); they read nothing but the room and whether the suggested folder is empty, create nothing, list nothing, name no path in an error. (d) `UserText` for the suggested path; accessible names; the room's line a polite status; colours from theme tokens; keyboard. (e) The guide says both. (f) Out of scope: the room for libraries already listed; a new cloud warning for the chosen folder.
